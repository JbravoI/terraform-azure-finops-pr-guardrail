# v0.1.0 Release Notes Draft

**Status:** Draft. Do not publish until the GitHub workflow evidence in the test matrix is complete.

## Highlights

- Evaluates Terraform plan JSON against mandatory-tag and cost-threshold policies.
- Produces a concise pull-request review comment with a stable update marker.
- Provides a composite GitHub Action and reusable workflow with restricted permissions.
- Includes sanitised fixtures for passing, missing-tag, threshold, and unknown-cost paths.

## Important limitations

- The current estimator uses fictitious prices for deterministic fixture tests. It is not an Azure pricing source.
- Infracost is the selected production provider, but live integration has not yet been implemented or validated.
- GitHub-hosted workflow and comment-update verification are required before publishing this version.

## Upgrade and adoption

1. Copy and review the baseline policy in `policies/default-policy.yml`.
2. Configure the reusable workflow with the Terraform directory and policy path.
3. Start with `review` outcomes for unknown costs, then move to `fail` only after ownership and exception processes are agreed.
4. Configure branch protection or rulesets to require the guardrail check for blocking policies.
